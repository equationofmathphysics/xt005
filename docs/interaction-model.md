# 交互和数据边界

| 数据 | 持有者 | 生命周期 |
| --- | --- | --- |
| PTY / 子进程 | 主服务 worker | 关闭终端或停止服务时回收 |
| 终端屏幕、滚动缓冲 | 主服务内存 | 浏览器可重连；服务重启后清空 |
| 工作区、排序、置顶、终端标签 | 工作区注册 JSON | 跨重启保存 |
| 会话原始历史 | CLI 本地 JSONL | 网页只读展示 |
| 标题、重要标记等 | 本地历史元数据 JSON | 跨重启保存 |
| 草稿、旧版未确认发送 | 浏览器 localStorage | 按工作区与会话保存；存储不可用时仅本页 |
| 抢救操作、回退路径 | 独立抢救状态目录 | 页面断开后继续；进程崩溃可手动回退 |

## 终端

“+ 终端”启动普通 shell，可以运行任意命令行 agent。
“+ Codex”是可选快捷入口，缺少程序或不支持独立模式时给出错误。
点击历史会话唤醒 CLI；“查看”只读打开历史，不加载模型或进程。

切换工作区、终端、关闭浏览器不会结束后台进程。“中断”仅发送 Ctrl-C，
需要查看终端确认效果。“卸载”确认后结束整个终端及其子进程。
CLI 退出后保留输出供检查，不自动重启它。服务重启会结束所有终端，
普通 shell 标签可恢复，已有历史会话需主动唤醒。

没有结构化可靠事件时，agent 状态显示未知，不能用静默或提示符判断完成。
终端输出中的活动提示只是辅助信息；可选旧 hooks 不构成运行依赖。

## 草稿与历史

草稿通过“粘贴到终端”交给程序，保留原稿供用户检查；不会自动当作成功提交而清除。
多行内容交给终端程序处理，使用前检查当前程序和输入位置。
历史对话可以在 CLI、模型账号不可用时查看；工具等未知事件折叠显示原始文本。
旧版配置与 fork 元数据文件保留，但不声称已映射为 CLI 功能或继续维护原结构化分支树。
模型、Fast、审批、fork、goal 等以所运行 CLI 的实际能力和命令为准；网页不再提供
绑定这些协议字段的控制项。

## 抢救

抢救页地址和管理令牌独立于主应用。停止、重启、更新和回退会提示确认。
主服务中的所有进程会受停止操作影响。操作在后台继续，重新打开页面可查看结果和日志。
